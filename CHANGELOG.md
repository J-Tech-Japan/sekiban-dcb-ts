# Changelog

## Unreleased matched set 0.2.2

Package versions in this repository stay at 0.2.1 and 0.1.3. The
release-preparation change moves the matched set to 0.2.2, moves the helper's
exact `@sekiban/dcb-runtime` dependency from 0.2.1 to 0.2.2, and publishes
`@sekiban/dcb-cloudflare` and `@sekiban/create-dcb` at 0.1.4. This changelog
entry does not publish a package.

### @sekiban/dcb-cloudflare 0.1.4

- Authorization callbacks receive the exact request, environment, and
  execution context. Callbacks that accept fewer arguments stay assignable.
- The helper README example uses `checkConfiguredBearer` from
  `@sekiban/dcb-runtime/cloudflare` and maps every non-authorized result to an
  explicit response. That export is available beginning with runtime 0.2.2.
  This change leaves the helper manifest's exact runtime 0.2.1 dependency
  unchanged.
- `forwardSerializedRoutes` is optional. Omitted or `true` keeps the five
  serialized paths. `false` vetoes each canonical built-in path before
  `extraPaths` and `extraPrefixes` are considered. Overlapping extras cannot
  restore a canonical path. A mount with `false` and no extras is valid.
  Non-overlapping extras still forward. A present non-boolean value fails
  fast.

### @sekiban/create-dcb 0.1.4

- Generated topology and guidance treat `REPAIR_OPERATOR_TOKEN` as optional
  until an `extraPath` or `extraPrefix` under `/operator`, or a direct runtime
  fetch export, is introduced. The unchanged project keeps `/operator/*`
  unmounted and does not require the secret.
- `deploy:check` classifies those source shapes offline, records
  `remoteStateChecked: false`, and removes the repair binding and both
  Cloudflare credential variables from the dry-run child environment. It does
  not read the secret value or verify remote state.
- The generated starter mounts only the maintenance prefix under
  `/internal/sekiban`. Application commands and reads call the runtime
  in-process. The stock `deploy:check` attests that exact maintenance-only
  mount. Added runtime paths or prefixes, or re-enabled serialized forwarding,
  fail before Wrangler. Projects generated by earlier versions can match the
  new default by setting `forwardSerializedRoutes: false` while retaining the
  `/maintenance` extra prefix.

### @sekiban/dcb-runtime

- Shared bearer checks fail closed when a binding is missing, empty, or
  whitespace-only. They hash both complete credentials with SHA-256 and
  compare every digest byte without early exit.
- `/operator/bootstrap/*` and both meeting-room conformance gates keep exact
  configured bytes. Unconfigured bindings return 404. Configured missing or
  wrong credentials keep 404/403 for bootstrap and 403 for conformance.
- `POST /operator/repair` returns 404 when `REPAIR_OPERATOR_TOKEN` is not
  configured. Configured missing or wrong credentials remain 401. Non-POST
  remains 404.
- Incident maintenance still trims its configured token, returns 503 when that
  binding is unconfigured, and returns 401 for a missing or wrong credential.
- Denied bootstrap and repair requests are rejected before service-identity
  resolution and before downstream storage or Durable Object access.
- Cloudflare-only sample deployment wrappers require a protected
  `REPAIR_OPERATOR_TOKEN` file and send it to Wrangler on standard input.
  Optional conformance provisioning uses the same file rule. The sample
  wrapper's `--dry-run` and `-- --dry-run` forms bundle only and perform no
  remote action.

### Serialized query parameters

- A scalar serialized query accepts only a parsed empty object. Any other parsed value is HTTP 400 `query_params_unsupported` with the message "The selected query does not support these parameters." The check runs after the query is resolved and before projector lookup, provider initialization, or a store read. A caller-supplied `{}` keeps the existing count result.
- A list query accepts only `PageNumber`, `PageSize`, `NewestFirst`, and `consistency`. An unknown own key receives the same 400. Callers that previously sent ignored list keys must stop sending them. `waitForSortableUniqueId` stays an outer request field. Value checks and defaults are unchanged.
- `@sekiban/dcb-client` maps `query_params_unsupported` to that same message and classifies the code as `invalid`. The thrown `ClientError` shape is unchanged.
- The meeting-room sample reads one room through `GET /api/read/room?roomId=...`, which returns the decoded `RoomProjector` tag state, its version, and `lastSortedUniqueId`.
- The create-dcb template uses the same keyed room read and returns `lastSortedUniqueId`. That template correction reaches npm with a later `@sekiban/create-dcb` release; the published `0.1.3` creator is unchanged.
- Typed query handlers are planned for `0.3.0`. Their API is not defined in this change. The V1 response envelope is unchanged.

## @sekiban/dcb-domain 0.2.1 (matched release)

### @sekiban/dcb-core 0.2.1

- Republished as part of the matched set. The range since the current
  published baseline contains no intended public API change for core.

### @sekiban/dcb-domain 0.2.1

- Republished as the matched-set authority for the current domain release
  notes; no additional public API change is intended by this version bump.

### @sekiban/dcb-client 0.2.1

- Republished with core and domain pinned to the same exact matched version.
  No intended public API change is introduced by this release preparation.

### @sekiban/dcb-runtime 0.2.1

- Fails closed when an explicitly selected Cosmos provider has missing or
  incomplete bindings, before client or network access.
- Adds the authenticated incident lifecycle maintenance API and its
  compatibility-safe HTTP maintenance paths, plus the experimental explicitly
  selected Cosmos provider and checked layout contract.
- Covers service-scoped outbox handling, append-receipt tag-write results,
  bootstrap write permits, cross-epoch duplicate replay corrections, allocator
  and import safeguards, PostgreSQL logical-event APIs, and shard-rotation
  APIs with ordering guards.

### @sekiban/dcb-cloudflare 0.1.3

- Tightens mounted-prefix validation and supports explicitly mounted
  maintenance prefixes through `extraPrefixes`.

### @sekiban/create-dcb 0.1.3

- Includes D1 migration `0021_incident_lifecycle.sql` for D1 deployments that
  use incident maintenance and for the upgraded starter.
- Adds the inactive experimental Cosmos descriptor, standalone deployment
  runbook, checked deployment topology, and `deploy:check`.

The PostgreSQL tag-rebuild command remains a repository-only tool and is not a
feature shipped in any package tarball.
