## AC3 matrix

The focused test is `test/g76-regression-matrix.spec.ts`, run with
`npx vitest run --config vitest.config.ts --maxWorkers=1
test/g76-regression-matrix.spec.ts`. Each row sends one
`G76RegressionMatrixEvent` candidate with payload
`{"fixture":"g76-regression-matrix"}` encoded at the public boundary. The
candidate's event ID is generated by CommitWorker; the test records that exact
ID in the participant ledger and asserts its retention. The attempt IDs below
are supplied through the existing test-only fault header so the receipt is
deterministic; no production request accepts that header.

The matrix adapter is a durable-participant fixture: append facts are recorded
before an acknowledgement is returned, fence facts are recorded before a
success acknowledgement or simulated lost acknowledgement, and cancellation
never deletes an event. Thus the fake cannot turn a bare 2xx into a safety
claim. The separate real Tag test below exercises the actual Tag storage
transaction, idempotence, stale epoch, and overlap gates.

## G35 caller meaning

`partial_write` means preserve the committed facts and reconcile or repair the
missing participants; never blindly resubmit. The undetermined outcome means
reread tag heads and event/query state before retrying, and retry only through
the established identity-preserving caller/event procedure. “Same identity”
means the supported caller/event idempotency identity, not a promise that an
HTTP replay preserves the internal attempt UUID generated by this boundary.
The source response text and retry semantics are unchanged.
